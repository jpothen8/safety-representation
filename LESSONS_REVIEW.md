# Review of the SafetyCubes experiment lessons

Reviewed 2026-11-02: the complete reference `CLAUDE.md` operational runbook, `meeting_report.md`, `ideas.md`, `project_summary.md`, `sim/README.md`, current simulator/config/expert/rollout/policy source, cleanup scout implementation, and `outputs/run_lambda_sweep.sh`. Historical numbers below are reported by the reference, not reproduced by this smoke.

| Lesson | Consequence for this experiment |
|---|---|
| AnyDesk/GLX can silently return black frames after remote disconnect; old sets lost 60–68% of frames | Force EGL and remove DISPLAY before importing MuJoCo. Audit both cameras on every accepted smoke trajectory. Never reuse pre-fix data merely because its file exists. |
| SSH disconnection killed previous background training | Use the server's tmux terminal and `scripts/run_experiment.sh`; keep timestamped logs. Current terminal has TMUX set. Sandbox cannot connect to the tmux socket, so detached tmux control is not verified from tool calls. |
| Reboots under sustained GPU load | Do not alter user-managed power/fan settings. Save resumable optimizer, trainable weights and RNG state atomically; evaluate one durable case at a time. CUDA/driver are currently unavailable. |
| Noninteractive python/uv paths are unreliable | Call the reference `.venv/bin/python` explicitly. Resolve caller paths before changing directory for reference assets. |
| Run visibility and restart matter | Timestamped tee logs, atomic JSON, progress checkpoints and per-case evaluation resume. The custom smoke uses local metrics; WandB integration requested by the historical runbook is not implemented here. Do not claim a remote dashboard exists. |
| Old README/design prose includes obsolete claims | Preserve executable task definitions and record the effective configuration. The runbook's geometry table (0.07 separation / 0.055 corridor / 0.030 carry) differs from this checkout's defaults (0.09 / 0.045 / 0.025). Do not silently substitute either scene. |
| Separation controls diversity; corridor clearance controls gripper safety | Keep them separate; do not shrink the finger corridor to make layout sampling easier. The tiny smoke uses this checkout's defaults and does not establish equivalence with every historical benchmark scene. |
| A* prefers free-gap centers; BFS hugged boundaries and fought the safety objective | Reuse the current A* expert and replanning rather than inventing an alternative task/expert. |
| Magnetic grasp has hidden state outside MuJoCo | Reuse full `snapshot/restore`, including attachment, offset and minimum grip position. A qpos-only snapshot is insufficient. Replan from the restored cube toward the goal. |
| π0 and diffusion normalization differ | Use the checkpoint's saved processors. Read its action stats for the inherited safety machinery; never treat normalized joint targets as radians in FK. |
| Per-step policy reset made gripper-close actions disappear | Reset once per episode and execute queued action chunks. Preserve the diffusion checkpoint's 50 executed actions and 56-step horizon. Changing receding horizon would be a separate arm. |
| α-mixed DAgger made incoherent targets and destroyed competence | Keep scout/perturbation actions outside supervised windows. Every action in a supervised chunk comes from an actually executed, coherent expert suffix. No hand-back to the scout. |
| Open-loop failures must be corrected where the chunk was planned | A near-boundary scout event triggers the most recent safe, grasped weave planning boundary. Save the trigger separately; do not branch at an arbitrary mid-chunk danger frame. The initial implementation missed this and has been corrected. |
| π0 and diffusion expose different queue APIs | The reference scout’s `_action_queue` check is not valid for this diffusion implementation. The diffusion wrapper now checks `_queues["action"]`; verify the implementation rather than assuming the shared wrapper makes every helper policy-agnostic. |
| `n_obs_steps=1` made old cleanup valid | Preserve the supplied checkpoint's observation count. The loader supports real history and excludes all pre-suffix actions even for longer histories; policy evaluation of arbitrary multi-history checkpoints still requires explicit history warmup and is not certified. |
| Placement undershoot can originate outside the near-goal band | Do not conflate collision recovery with placement-anchor DAgger. Placement gates are a documented follow-up; do not silently change chunk length or success criteria to improve scores. |
| Short NVENC clips sometimes emitted no file; AV1 broke aggregate metadata matching | Use software H.264 for representative videos. NPZ smoke data avoids LeRobot video-schema aggregation; future native dataset aggregation must match codec/GOP metadata. |
| λ=0 is a strong baseline, not an unsafe strawman | Start A/B/C from the supplied nominal diffusion checkpoint. The reported diffusion sweep gives 88.5% success at λ=0 and no significant success win at λ=0.25. Primary experiment uses only imitation; no classifier/RL/filter. |
| Old softplus penalized safe expert behavior, wrong body and wrong geometry | Do not add this loss to the primary recovery arm. Actual simulator ceiling uses the held cube's center, not a TCP frame 10 mm higher. Actual contacts include held cube and fingers. |
| Mean clearance improved while collision tails worsened | Report actual substep collision/height events, safe task success and low-margin tails. Never infer safety from a larger mean clearance. Use paired seeds and paired statistics when sample size supports them. |
| Revised hinge could be completely inert | A future surrogate arm must check nonzero penalty/gradients, expert silence and actual contact firing. The final documented gates are obstacle 1.0 and ceiling 0.25; the earlier shared 0.25 setting was inert. |
| Geometry approximation can be wrong despite a good aggregate score | Keep the 91-sphere covering and held-cube term for optional surrogate work; verify by body, against mesh/MuJoCo distance. Never size mesh spheres from geom_size or trust unnamed geom labels. Primary collision labels use simulator contacts. |
| More safety weight can crush imitation gradients | If separately evaluating safety penalties, use hinge, 5 mm margin, distinct noise gates and early gradient-norm diagnostics. Do not transfer λ across policy classes using loss ratios alone. |
| Training/evaluation leakage inflated earlier scores | Use disjoint new parent seed splits and complete trajectories. Keep nominal retention (known layouts) separate from held-out and boundary suites. Historical checkpoint split is not independently certified. |
| Tiny stochastic runs give unstable rankings | One training seed and one paired case per smoke suite check execution only. Larger config has multiple training seeds; do not claim statistical improvement from the smoke. |

The existing six validated nominal/recovery trajectories and B/C one-update checkpoints are pipeline artifacts, not an answer to the research question. No completed A/B/C evaluation table existed at the restart. The interrupted tool process handles were no longer available; evaluation must be resumed from durable per-case output, not assumed to have survived.
